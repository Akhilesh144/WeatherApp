# Weather App

A simple weather application built with React that fetches real-time weather data using the OpenWeatherMap API.

## Features

- Search weather by city name
- Display temperature
- Display humidity
- Display wind speed
- Display weather icon
- Display weather description
- Handles invalid city names
- Shows default weather for London on startup

## Technologies Used

- React.js
- JavaScript
- CSS
- Vite
- OpenWeatherMap API

This project uses the **OpenWeatherMap API** to fetch weather information.
